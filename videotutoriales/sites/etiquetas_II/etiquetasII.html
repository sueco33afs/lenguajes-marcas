Etiquetas 'video'

En HTML5, la etiqueta <video> se utiliza para insertar contenido de video en una página web.

Etiquetas 'audio'

En HTML5, la etiqueta <audio> se utiliza para insertar contenido de audio en una página web.

Etiquetas 'favicon'

La etiqueta <link> con el atributo rel="icon" se utiliza para especificar el favicon de una página web. 

<link rel="icon" href="images/css3.png" type="image/x-icon" />

Etiquetas 'iframe'

La etiqueta <iframe> se utiliza para incrustar otro documento HTML dentro de la página actual.
