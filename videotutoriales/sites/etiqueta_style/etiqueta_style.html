Introducción a los estilos

Atributo style

El atributo style sirve para aplicar el formato a través del lenguaje CSS.

  • 'style' Incrusta CSS dentro del documento HTML. Va en el 'head' y permite definir estilos para elementos HTML.
  • 'br' (line break) Inserta un salto de línea dentro de un texto. Es un elemento vacío (void element): no tiene etiqueta de cierre.

    En un lugar de la mancha
    de cuyo nombre no quiero acordarme.
    No ha mucho tiempo que vivía un hidalgo de los de lanza en
    estocada.

  • 'pre' (preformatted text) Enfocada a contener código de programación, muestra el texto tal cual está escrito: conserva espacios, tabuladores y saltos de línea, y usa fuente monoespaciada por defecto. Normalmente HTML colapsa los espacios en blanco; 'pre' lo evita.

    Ejemplo de JavaScript:

                    for (const i; i < 10; i++) {
                  alert ("Dime un número: " + i);
                }
