Los formularios web son utilizados para hacer login, hacer pedidos, introudcir datos en general.

Los formularios se introducen con la etiqueta 'form'

El atributo action indica que a que página van dirigidos los datos. Es común que la página no esté en html, sino en un lenguaje d eprogramación muy común del lado del servidor que se llama php. Por eso es común que la página de destno tenga extensión .php.

Para este ejemplo, la página aún no existe.

El otro atributo típico de la etiqueta form es method. Este atributo tiene dos valores:

  • get, los datos serán visibles en la url y están por tanto limitados a la longitud de la url (es la opció si no se pone nada). No es adecuada por tanto para enviar contraseñas o archivos muy grandes.
  • post, los datos no serán visibles en la url y no están limitados. Se pueden enviar contraseñas sin que se vean o archivos grandes.

La etiqueta fieldset no es un elemento obligatorio, pero queda bien para agrupar campos, como "Datos Personales", "Datos Bancarios", ... etc. La etiqueta del grupo de datos se introduce con 'legend'

Etiqueta 'label'

Sirve para asociar un 'input' con la etiquetita que tiene delante. Esto es, 'nombre', 'apellidos', ... No es imprescindible pero aporta dos cosas:

  • Al hacer click en la etiqueta, el foco 'el cursor', se sitúa en el input que tiene asociado. Eso lo hace más accesible.
  • Permite aplicar estilo CSS a todas las etiquetas a la vez, consiguiendo un aspecto más homogeneo.

Ejemplo:

Datos Personales




La manera de dar CSS a todas las etiquetas 'label' es poniendo el nombre de la etiqueta entre llaves
