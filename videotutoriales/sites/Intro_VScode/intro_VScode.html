Introducción a VS Code

VS Code es un editor de texto liviano pero potente, desarrollado por Microsoft.

Visual Studio Code


  • Visual Studio Code es uno de los editores html más utilizados y pertenece a microsoft.
  • La primera vez que se instala aparece en inglés, pero se puede cambiar a español instalando un componente.
  • En el icono de extensiones, en la barra de busqueda escribimos Spanish, seleccionamos la herramienta, la instalamos y reiniciamos VScode.
  • Hay varias formas de crear un nuevo archivo, la más comun es irnos a menú -- archivo y nuevo archivo de texto. Tras crearlo, hay que guardarlo con la extension correspondiente; .html, .css, .js ... etc.
  • Si lo guardamos como archivo .html, al abrir el archivo, una vez reconoce VScode que es un archivo .html, nos ofrece una serie de ventjas como la de escribir el simbolo ! y al pulsar TAB nos completa con la estructura básica de una página.
  • Instalando la extensión Live Preview, podemos visualizar como esta quedando la pagina e ir viendo cada modificación que hacemos.
  • Para los enlaces usamos la etiqueta 'a', las etiquetas de apertura pueden llevar atributos, el atributo 'href' es propio de esta etiqueta.
  • Vscode tambien nos permite customizar la herramienta cambiando el tema, el tamaño de la fuente y la fuente.
