Listas

Otro elemento muy común en las páginas son las listas. Hay de dos tipos, con orden (numeradas), o sin orden (no numeradas)

Lista Ordenada 'ol'

Las listas ordenadas empiezan por la etiqueta 'ol' - ordered list -

Ejemplo:

  1. Abrir el editor
  2. Crear una página nueva
  3. Guardarla como .html
  4. Publicarla en un servidor

Con el atributo 'type="a" ' podemos elegir entre números o letras para ordenar.

Lista sin ordenar 'ul'

Las listas no ordenadas se crean con la etiqueta 'ul' - unordered list -

Ejemplo:

  • HTML
  • CSS
  • JavaScript
  • PHP

Con el atributo 'style="list-style-type: circle' podemos cambiar el aspecto del punto
