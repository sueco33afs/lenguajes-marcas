Git

Git es un sistema de control de versiones distribuido que permite a los desarrolladores rastrear y gestionar cmaibos en el código fuente de un proyecto.

  • Control de versiones: Permite llevar un registro de las modificaciones realizadas en el código a través del tiempo.
  • Ramas (Branches): Git permite crear aramas para trabajar en nuevas características o arreglos de errores sin afectar el código principal.
  • La descarga de Git la hacemos desde

Tras la instalación buscamos el programa Git Bash. Que es un intérprete de comandos donde podemos ejecutar comandos del Git.

Para configurar su nombre de usuario de Git, siga estos pasos:

  • En la línea de comando, escriba el siguiente comando Git: git config --global user.name "your username"
  • Para configurar su dirección de correo electrónico de Git, escriba el siguiente comando de Git: git config --global user.email "your email address

Repositorio de Git

Nos vamos a VS Code y pulsamos en el icono de Source Control y a continuación pulso en inicializar repositorio.

Veo todos los archivos sin guardar en el repositorio. Pongo un nombre y pulso en confirmación, quedando los cambios guardados en el repositorio local.

Ahora los publicaremos en GitHub, para eso le ponemos un nombre y pulsaremos en Publish Branch, de momento todo el proyecto queda almacenado en la rama main.

Me logeo en mi cuenta de GitHub a través del navegador. Debo tener ya creada una cuenta. Vuelvo a VS Code y en la barra superior Open Quick Access indico el nombre del repositorio.
