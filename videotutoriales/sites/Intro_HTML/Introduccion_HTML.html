Introducción a HTML

HTML (Lenguaje de Marcado de Hipertexto) es el lenguaje de marcado estándar para crear páginas web.

El archivo HTML

  • Las páginas web son realmente archivos de texto que el navegador interpreta y muestra de forma entendible par los humanos.
  • Para crear una página web, no hece falta programas especiales, nos basta un editor de texto básico como el bloc de notas de windows.
  • HTML tiene una serie de MARCAS que van entre los signos de < y >, donde cada marca indica una cosa. La mayoría de las marcas abren (< >) y cierran (</ >). Por ejemplo, todo el documento va entre las marcas (<html>) y (</ html>).
  • El documento se divide en dos parte head (metadatos), y body (lo que se ve en pantalla)
  • Una etiqueta que se suele poner en el HEAD es (<title>) y (</ title>). Que contiene el título de la página que luego vemos en la solapa del navegador.
  • Otra etiqueta básica son los títulos h1, h2, h3, ... h6
  • 'hr' es una etiqueta que no tiene cierre y pinta una linea horizontal
  • Para hacer párrafos ponemos el texto entre las etiquetas (<p>) y (</ p>)

El lenguaje HTML fue inventado por Tim Berners Lee en 1990 en el CERN (Suiza) y es la base de todas las páginas web.

Al archivo le pongo el nombre primera.html, es muy importante guardarla con la extensión .html
