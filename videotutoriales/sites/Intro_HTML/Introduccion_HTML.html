Introducción a HTML

HTML (Lenguaje de Marcado de Hipertexto) es el lenguaje de marcado estándar para crear páginas web.

El archivo HTML

  • Las páginas web son realmente archivos de texto que el navegador interpreta y muestra de forma entendible par los humanos.
  • HTML tiene una serie de MARCAS que van entre los signos de mayor que y menor que, donde cada marca indica una cosa.
  • El documento se divide en dos parte head (metadatos), y body (lo que se ve en pantalla)
  • En el HEAD se suele poner el título que se ve en la pestaña del navegador.
  • Otra etiqueta básica son los títulos h1, h2, h3, ... h6
  • 'hr' es una etiqueta que no tiene cierre y pinta una linea horizontal
  • Para los párrafos usamos 'p'
  • El documento creado debe de llevar la extensión '.html'
