3 Formas de aplicar CSS a una página web

Como incluir estilos

Estilo en línea

Es un método de aplicar CSS directamente a un elemento HTML utilizando el atributo style. 

<h1 style="color: blue;">Título</h1>

Hoja de estilo interna

Es un método de aplicar CSS dentro de la etiqueta <style> en el interior de la etiqueta <head>. 

<style>
  p {
    color: green;
    font-weight: bold;
    font-size: 2em;
  }
</style>

Hoja de estilo externa

Es un método de aplicar CSS mediante un archivo externo con extensión .css que se enlaza a la página HTML. 

<link rel="stylesheet" href="estilos.css">
